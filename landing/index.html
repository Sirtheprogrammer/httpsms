Everything to run SMS from your own server

Pair with a QR code

Scan once from the app. Dual-SIM phones work, with SIM, battery and signal shown live.

AI agents, visually

Drag-and-drop workflows: trigger, AI agent, condition, send SMS, HTTP call. Agents remember each conversation.

Bring your own key

OpenAI, Anthropic, Gemini or DeepSeek. Keys are encrypted on your server and only you can use them.

Simple REST API

Send with one POST. Scoped tokens, idempotency keys and signed webhooks with retries.

Multi-user

Everyone gets their own phones, messages and workflows. One admin manages users and app updates.

Stays online

Foreground service, auto-reconnect, restart after reboot and a watchdog against aggressive battery savers.

Up and running in three steps

  1. 1

    Start the server

    Run it with Docker on any machine your phone can reach, then create the admin account.

  2. 2

    Install & pair

    Install the APK, tap Scan pairing QR and point it at the dashboard. Done.

  3. 3

    Automate

    Send from the API or let a workflow answer incoming texts with the AI model you choose.

Self-host in a minute

Your messages and keys never leave your server. One container, SQLite storage, no external services.

Download APK Read the docs 
# clone and start
git clone https://github.com/Sirtheprogrammer/httpsms.git
cd httpsms
docker compose up -d

# open http://localhost:8080 and sign up

# send an SMS
curl -X POST http://localhost:8080/api/v1/sms/send \
  -H "Authorization: Bearer htsms_live_…" \
  -d '{"recipient":"+255712345678","body":"Hello!"}'
